rainbowpca

rainbowpca is an R package for mapping continuous genetic structure using RGB-encoded principal components. By converting principal component (PC) axes into red, green, and blue color channels, this package provides a simple and intuitive way to visualize spatial patterns of genetic variation, where samples with more similar colors have more similar genetic composition.

A major advantage of this visualization is that it represents genetic variation continuously rather than discretely. The transitions between colors can therefore reveal whether turnover in genetic structure across space is gradual or abrupt. In contrast, visualizations based on discrete clusters require users to specify the number of genetic groups and treat all transitions between groups as equivalent, making it difficult to distinguish between gradual clines and sharp breaks.

Although developed primarily for population genetic and landscape genomic analyses, rainbowpca can be applied to any dataset where the first three principal components capture meaningful continuous structure.

Installation

You can install the development version of rainbowpca from GitHub with:

# install.packages("pak")
pak::pak("AnushaPB/rainbowpca")

Example

Load libraries:

library(rainbowpca)
library(vcfR)
library(dplyr)
library(sf)
library(ggplot2)
library(tigris)
library(cowplot)

Run PCA: (Note - you can also run PCA externally using your program of choice and import the first three PCs as a data frame. Just make sure the order matches your coordinates!)

# Load example data
data("liz_coords")
data("liz_vcf")

# Extract genotype matrix
gt <- extract.gt(liz_vcf, element = "GT", as.numeric = TRUE)

# Impute missing values
gt[is.na(gt)] <- median(gt, na.rm = TRUE)

# Prepare matrix for PCA
gt <- t(gt)
gt <- gt[, apply(gt, 2, var) > 0]

# Run PCA
pca_result <- prcomp(gt, center = TRUE, scale. = TRUE)
pcs <- pca_result$x[, 1:3] # First three PCs

If you wanted to use your own PCA results, you would do it here instead of the above code. For example: pcs <- read.csv("my_pca_results.csv")

# Convert first three PCs to RGB colors
rgb_df <- pca_to_rgb(pcs)

# Combine coordinates and colors
plot_df <- 
  st_as_sf(liz_coords, coords = c("x", "y"), crs = 4326) %>%
  bind_cols(rgb_df) %>%
  bind_cols(pcs) 

# Load background map 
conus <- 
  states(cb = TRUE, resolution = "20m") %>%
  st_transform(crs = st_crs(plot_df)) %>%
  st_crop(plot_df)

# Plot PCA

  ggplot(plot_df) +

# Plot map

  ggplot(plot_df) +

# Combine

This example map shows the continuous genetic structure of Sceloporus occidentalis across the western US based on RGB-encoded PCA axes.

Related approaches

This approach is inspired by Generalized Dissimilarity Modelling and the gdm package, which uses a similar approach to visualize compositional dissimilarity across space. RGB encoding of principal component axes has also been used previously in population genetics and related fields, including the colorplot() function in the adegenet package; rainbowpca extends this idea by providing a generalizable and reproducible mapping workflow.
